Tools
=====

- **I bmerawdata**

I bmerawdata
---------------

This tool allows you to record and save data with your BME688 breakout board, so that it can be imported by [Boschs AI Studio](https://www.bosch-sensortec.com/software-tools/software/bme688-software/).
To use the smell detection feature of the BME688 you need to train an algorithm in AI Studio.
